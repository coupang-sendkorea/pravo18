# pravo18

Статический сайт-визитка юридической компании «Ваш Юрист».

В текущей версии отсутствуют формы обратной связи, аналитические счетчики, cookies/localStorage, сторонние шрифты/CDN и клиентские скрипты отправки данных.


Добавлен статический раздел «Стоимость юридических услуг» на основании перечня из файла «для сайта.xlsx». Раздел работает без JavaScript и не собирает данные посетителей.
